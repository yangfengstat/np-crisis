# Computational definition and data alignment

## Fixed score and independent NP calibration

For every fit, a seeded random half of crisis observations (floor of the crisis count divided by two) joins every noncrisis observation in the score-fitting subset. The remaining crisis observations form the NP calibration subset. All preprocessing is fitted on the score-fitting subset: columns entirely missing there are removed, remaining missing values use its feature medians, and features are ranked by their two-sample Kolmogorov statistic. Ties in feature ranking use alphabetical order. No calibration label or feature selects the score, predictors, transformations, or hyperparameters.

The five reserve-coverage columns `RES_BMGS`, `RES_BM`, `RES_GDP`, `RES_CH_GDP`, and `RES_D_S` are excluded before fitting. `DB_GDP_BIS_FC` is also excluded, preserving the original nonvarying-feature exclusion. The full usable backtest dimension is 66. Early annual samples can have fewer usable columns because historical predictors are entirely missing.

Signal extraction is a fixed composite. For each feature, fitting-sample empirical quantiles at 0.10, 0.15, ..., 0.90 (R quantile type 1) and both directions of the inequality are considered. Each candidate has half-count-corrected true-positive and false-positive rates `(count+0.5)/(class count+1)`. The candidate minimizing false-positive rate divided by true-positive rate is selected; candidate-order ties prefer the positive direction, then the smaller cutoff. A component receives weight proportional to `max(0,TPR/FPR-1)`, normalized to sum to one. If every weight is zero, equal weights are used. This entire composite is fitted once, before any NP alpha is selected.

Ridge logistic regression uses `glmnet`, binomial likelihood, alpha=0, lambda=0.01, fitting-sample standardization, convergence tolerance 1e-8 and maximum 100000 iterations. An error is raised for nonzero convergence status. SVM uses a radial kernel, default cost, and fitting-sample scaling. Random forests use 500 trees and default feature sampling. AdaBoost uses 50 discrete exponential-loss boosting iterations, shrinkage 0.1, and the package's default tree and subsampling settings except that unused within-tree cross-validation is explicitly disabled (`rpart.control(xval=0)`). The diagnostic cross-validation was not used to select tree size; disabling it changes the seeded random-number stream, so all AdaBoost point, backtest, and bootstrap results are rerun with this explicit setting. Hyperparameters do not depend on the evaluation years. All score orientations are chosen so larger means greater crisis risk.

For m held-out crisis scores ordered increasingly, threshold index k is the largest index satisfying `P(Binomial(m,alpha) <= k-1) <= delta_NP`, where delta_NP=0.1. Warnings use `score >= threshold`, so score ties are handled conservatively. A numerical binomial tolerance of 1e-12 handles beta-quantile inversion roundoff. If no finite threshold is feasible, all observations receive warnings. At alpha=1, none do. The finite-sample guarantee is conditional on a fixed scoring procedure and independent, identically distributed calibration observations from the crisis class. The dependent country-year panel is not certified to satisfy this iid assumption; its backtest is an empirical assessment.

## Complete alpha minimization and ties

The policy changes only at `a_k = qbeta(1-delta_NP,k,m+1-k)` for k=1,...,m. Annual calibration evaluates 0, all these breakpoints, and 1. The all-warning policy applies on `[0,a_1)`; the kth threshold applies on `[a_k,a_(k+1))`, with the last finite policy ending at 1. Alpha=1 is separately all-normal. The tests independently compare beta inversion with the binomial tail and check policy constancy inside each interval.

For each candidate policy, the aggregate warning signal is the unweighted country mean of binary warning indicators, clipped only after averaging to [0.001,0.999]. This same definition is used for both SE and AdaBoost and in the recovery exercise. It is a decision-based signal, not an isotonic-calibrated posterior probability.

The observed aggregate reserve ratio is matched by minimizing its squared deviation from the constrained insurance prediction. All minimizers within absolute/relative tolerance `1e-10*max(1,min_loss)` are reported. The scalar index is the smallest minimizing alpha. Output `argmin` contains all minimizing candidate lower endpoints; `intervals` is their actual union of half-open policy intervals plus `{1}` if applicable. `alpha_upper` is the supremum of that union and `upper_included` says whether it is attained. A minimum and supremum alone must not be described as an interval if the union has gaps. No smoothing is applied.

The insurance policy uses kappa=pi.bar+delta.op, A=1-(r-g)*lambda/(1+g), B=1-gamma-(1+r)*lambda/(1+g), eta=[q*(1-kappa)/((1-q)*kappa)]^(1/sigma), and reserve ratio max(0,(eta*A-B)/(1-kappa+kappa*eta)). Welfare is evaluated directly at the resulting positive consumption in both states. Numerical optimization tests include both interior and zero-reserve cases. The implementation imposes no additional upper reserve cap beyond positive consumption implied by the model.

## Dates and historical inputs

Both stages use the September 18, 2019 external database: `External_database_withSuddenStopGI_19802019_public_09_18_2019_forecasting_h1_v12.dta`. Its `Year` is the crisis target year. The bundled Stata variable labels identify most explanatory variables and `RES_GDP` as measurements from the previous year; scheduled debt amortization is a known target-year exception. Crisis labels match the crisis-identification file at the same calendar year. No unexplained plotting shift is applied.

For the index plotted at year t=1993,...,2017:

1. Score fitting and NP calibration use labeled database rows with `Year <= t-1`.
2. Forecast features come from the database row with `Year=t`, generally measured in t-1. Every country is forecast, including rows whose eventual crisis label is missing.
3. Insurance parameters use crisis-history and global-shock observations through t-1.
4. The reserve target is the country median of `RES_GDP` from database rows `Year=t+1`, because that column measures actual reserves in t. The final 2017 target therefore uses the available 2018 row.

This alignment is retrospective and descriptive. Reserves observed in t can respond to crises in t, and other reserve motives are unmodeled. It is not a strict real-time reconstruction of a policymaker's information or preferences.

The insurance calibration uses historical median capital-flow declines in crisis years for lambda; the average of the median growth decline across all crisis years and the median across crisis years with output decline for gamma; median noncrisis growth for g; the mean crisis indicator for pi.bar; and median global risk premium for delta.op. The original duplicated gamma-output-decline term is corrected. r=.05 and sigma=2 are held fixed. Bootstrap resampling recomputes all country-dependent historical parameters, while the common global-rate history remains unchanged.

There are 53 countries and 2014 country-year calendar rows during 1980-2017. Of these, 1932 have nonmissing classification labels and 82 are crisis observations, so the labeled-sample event proportion is 82/1932=0.04244306. The historical insurance baseline uses its own crisis-identification panel mean, not the labeled-classification denominator.

## Backtest and bootstrap

Backtesting fits on labeled rows through 2007 and evaluates labeled rows 2008-2017. The fitting/calibration split is held identical across model and feature-dimension comparisons. Feature dimensions are 10,20,30,40,50,60,and all usable features. The NP AUC integrates the actual step curve over [0,1] and AUPC over [0,.25], including the all-warning fallback; it is not a trapezoidal approximation on a coarse grid. The classic AUC uses the same fixed scores and test rows, with average-rank handling of ties. Reporting the best feature dimension within this test table is descriptive and is not an independent estimate of selected-model performance.

Country bootstrap samples 53 country identifiers with replacement, retains all time rows for each sampled block, and reruns score fitting, NP calibration, insurance calibration, reserve aggregation, and minimization. Repeated countries remain repeated blocks. New seeded fitting/calibration splits are used inside each replicate. The SE analysis uses 500 replications; AdaBoost sensitivity uses 200 because each full annual bootstrap trajectory requires substantially more computation. The bands are point estimate plus/minus one bootstrap standard deviation, clipped to [0,1], and are descriptive variability bands rather than validated confidence intervals. The country-year dependence and repeated blocks preclude interpreting each bootstrap fit as a fresh iid NP guarantee.

## Output columns

`outputs_corrected/empirical/annual_estimates.csv` has one row per learner and reserve year. `alpha` is the smallest minimizing bound; `alpha_max` is the largest minimizing candidate lower endpoint, which is generally not the supremum. `alpha_upper` is the supremum, `upper_included` identifies whether that supremum is attained, and `intervals` preserves the full union. `argmin` lists the minimizing candidate lower endpoints and `n_ties` counts them. These candidate counts do not count the infinitely many points inside a minimizing interval.

`observed` and `reserve` are ratios to GDP, not percentages. `mse` is the minimum squared discrepancy between those ratios. `share_raw` is the country warning fraction and `share` is its clipped value. `mode` identifies a finite threshold, all-warning fallback, or all-normal endpoint. `n_train`, `n_crisis`, and `m` count labeled historical observations, historical crises, and held-out calibration crises. `n_forecast` is the number of country blocks forecast and `d` is the number of usable predictors. `alpha_min_finite` is the first bound permitting a finite NP threshold. All empirical reserve figures multiply ratios by 100 to display percentage points of GDP.

`reserve_matching_paths.csv` contains every candidate alpha, raw/clipped warning share, threshold mode and value, calibration count, and implied reserve ratio before minimization. `insurance_calibration.csv` contains one row per year and the parameters used in that year's policy mapping. `bootstrap_MODEL_raw.csv` repeats the annual summary with an additional `rep` identifier. Its summary file gives the actual number `B`, mean, standard deviation, 5th and 95th percentiles of selected alpha, and the frequencies of multiple minimizing candidates and endpoint selection. These percentile columns are descriptive summaries and are not advertised as validated confidence limits.

`outputs_corrected/backtest/metrics.csv` contains one row per learner and feature dimension. `np_auc` and `np_pauc` are the unnormalized areas over [0,1] and [0,0.25], `roc_auc` is ordinary rank-based AUC, `m` is the held-out crisis count, and `delta` is the NP violation tolerance. `np_curves.csv` retains each switching bound, test specificity, and test missed-crisis rate; `roc_curves.csv` retains test false-alarm and detected-crisis rates. The three wide CSV files provide the exact values underlying the three panels of Table 3.
