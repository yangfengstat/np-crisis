# NP Crisis (Reproducible Repo)

This repository is a **clean, self-contained** version of the original project for reproducing the tables and figures generated by `NP_Crisis.Rmd`.

## Contents

- `NP_Crisis.Rmd`: main analysis (knit this file).
- `np-crisis-helper-funcs.R`: helper functions sourced by the Rmd.
- `data/`: input datasets needed by the Rmd.
- `outputs/rds/`: cached intermediate results (`.rds`) used to make reproduction fast by default.

## Reproduce the results

From the repo root:

0. (Optional) Minimize the lockfile to only used packages:
   - `R -q -f scripts/minimize-renv.R`

1. Restore the R package environment (recommended):
   - `R -q -f scripts/restore-renv.R`

2. Render the report:
   - `R -q -f scripts/render.R`

This produces `NP_Crisis.html` and writes generated artifacts (CSVs/figures) under `outputs/`.

## Notes

- If you use Quarto directly (e.g., `quarto preview NP_Crisis.Rmd`), you still need step (1) first; this repo uses `renv` (via `.Rprofile`) so packages must be installed into the project library.
- `rmarkdown::render()` requires Pandoc. Installing RStudio Desktop is the simplest way to get Pandoc on most systems.
- If you don't have Pandoc (or only want the figures/CSVs), you can knit without rendering:
  - `R --vanilla -q -f scripts/knit.R`
- By default, `NP_Crisis.Rmd` sets `use_cached_rds <- TRUE` and will reuse the cached files in `outputs/rds/` when present.
- If you set `use_cached_rds <- FALSE`, the notebook will recompute models and (depending on the chunk settings) can take a long time (e.g., the bootstrap section is configured for hundreds of replications).
